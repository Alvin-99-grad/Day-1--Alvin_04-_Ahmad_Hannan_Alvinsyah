# Dokumentasi Workshop

## 1. Rangkuman Materi
Workshop ini membahas integrasi antara pemanfaatan AI dalam pembuatan kode program dan manajemen perubahan berkas menggunakan Git serta GitHub.
**Prompt Engineering**: Metode merancang instruksi yang spesifik (mencakup Role, Task, Context, dan Format) agar model AI menghasilkan kode yang akurat dan siap pakai.
**Git vs GitHub**: Git merupakan sistem lokal untuk melacak riwayat perubahan berkas. Sementara GitHub adalah platform berbasis web untuk menyimpan repositori tersebut secara online dan mendukung kolaborasi.  
**Alur Kerja Git:** Memahami tiga area utama dalam Git, yaitu *Working Directory* (ruang kerja lokal), *Staging Area* (indeks persiapan), dan *Repository* (penyimpanan permanen).
**Perintah Dasar Git & GitHub:**
    *   `git init` : Membuat repositori lokal baru.
    *   `git add .` : Memindahkan seluruh pembaruan berkas ke staging area.
    *   `git commit -m 'message'` : Menyimpan riwayat perubahan secara permanen.
    *   `git push origin main` : Mengirimkan salinan kode lokal ke GitHub.
**Autentikasi SSH:** Cara membuat kunci keamanan digital menggunakan perintah `ssh-keygen -t ed25519` untuk menghubungkan perangkat lokal ke GitHub secara aman tanpa perlu mengisi kata sandi berulang kali.
